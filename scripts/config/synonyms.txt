# CJK↔English synonym groups for KB cross-lingual matching.
# Terms on the same line are treated as equivalent: when any term
# appears in a token list, all other terms on the same line are added
# to the token list before FTS5 indexing / MATCH escaping.
#
# This bridges the gap between Chinese documentation queries and
# English code identifiers: a paragraph mentioning "释放内存" becomes
# findable by the English query "free memory", and vice versa.
#
# Format: one group per line, terms separated by whitespace.
# Lines starting with # are comments. Blank lines are ignored.
# Each term may appear in at most one group (groups are merged if a
# term repeats). Keep groups small (2-4 terms) to avoid index bloat.
#
# Loaded by _builder/utils.py::_load_synonyms() and applied during
# _cjk_pre_tokenize() (write side) and _fts5_escape() (query side).
